통합시험은 `quality_status: reference_fallback_no_verified_mixed_improvement`를 반환했습니다. 이 fixture에서는 혼합학습의 개선을 확인하지 못해 기준 가중치를 보존한 것입니다. 이것을 “한국어 성능 향상”이나 제품 정확도로 제시하지 않습니다. 선택된 저장 형식은 INT8입니다.

## 환경

Linux x86-64, CPython 3.13.5, PyTorch 2.10.0+cpu, NumPy 2.3.5, safetensors, C++17 컴파일러. 실제 Rust tokenizers/Transformers/pyarrow는 이 제작 런타임에 설치되어 있지 않으며 외부 네트워크 다운로드가 제한되어, 원본 사전학습 모델과 공개 대용량 데이터 통합시험 대신 byte-token fixture를 사용했습니다. 독립 설치 시험은 `nanodecision2==0.3.1`의 설치 경로와 기본 recipe를 실제로 확인했습니다.

## 실행하지 못한 것

**실제 500만 행을 다운로드·정제·학습한 것이 아닙니다.** 공개 모델/원천의 설명과 형식을 조사하고 읽기·변환 코드를 작성했으나, 모든 현재 endpoint·원본 shard·Parquet 스키마를 직접 다운로드하여 검증하지는 못했습니다. 원천이 바뀌거나 정제 후 언어별 수량이 부족하면 사용자의 실행에서 추가 수정이 필요할 수 있습니다.

아래 항목은 미측정입니다.

- 실제 mmBERT-base 가중치와 원본 Transformers의 parity. 코드에서 필수 검사하지만 이 환경에서는 실행하지 못했습니다.
- 실제 Rust tokenizer와 대규모 Parquet 데이터를 연결한 5M 구성, 번역/근접 중복 품질 감사.
- RTX 5090, CUDA BF16, 실제 장문/다수 후보의 VRAM·처리량·총 학습시간.
- Windows/MSVC 및 PowerShell→WSL 실행기 전체.
- 본학습 후 영어/한국어 정확도, Julia 1/Laya 실가중치 비교 또는 초과 성능.
- 모든 입력에서 영어 성능 보존. 구현된 기준은 고정 검증셋의 관측 정확도/NLL 조건입니다.
- 대형 C++ 모델의 처리량·전체 메모리, 8K 이해력, 실서비스 안정성.

따라서 이 배포물은 **한 명령의 전체 경로와 오류/재개 동작을 소형 시험으로 검증한 구현**입니다. 500만 행의 실제 완료나 모델 우월성을 보증하는 자료가 아닙니다.
